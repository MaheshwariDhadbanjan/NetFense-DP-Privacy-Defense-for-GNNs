# NetFense-DP-Privacy-Defense-for-GNNsNetFense-DP: Privacy Defense for Graph Neural Networks
📌 Overview

NetFense-DP is a privacy-preserving defense framework designed to protect Graph Neural Networks (GNNs) from adversarial privacy attacks.
Graph-structured data often contains sensitive relational information, making GNNs vulnerable to attacks such as membership inference and model inversion. This project introduces a defense strategy that enhances robustness while maintaining model utility.

The system integrates differential privacy principles with adversarial defense mechanisms to reduce information leakage during training and inference.
